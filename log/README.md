# Phase III progress log

This directory tracks the engineering progress of Phase III — authenticated evidence ingestion.
Every progress increase must have a dated entry that explains the code or tests added, the evidence
used to assess that increase, the known limitations, and the next acceptance criteria.

- [Phase III progress history](phase-3-progress.md)

## Reporting rules

1. Percentages are estimates of Phase III scope completed, not test-pass percentages.
2. A commit is not considered verified just because it was pushed.
3. CI status is recorded against the exact commit SHA and linked to its GitHub Actions run.
4. When progress increases, update the history and commit the log together with the meaningful
   implementation change that earned the increase.
5. If CI is failing or pending, state that explicitly and keep production-readiness claims separate
   from implementation progress.
